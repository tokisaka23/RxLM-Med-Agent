# 🏥 RxLM-Med: Clinical Decision Support Agent via Multimodal RAG

![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg) ![Python](https://img.shields.io/badge/Python-3.10%2B-green) ![Model](https://img.shields.io/badge/Model-Qwen2.5--VL-yellow)

**RxLM-Med** is a multimodal clinical agent designed to bridge the gap between unstructured medical records (EHR images, lab reports) and evidence-based clinical guidelines. 

It integrates **Visual Instruction Tuning** with **Retrieval-Augmented Generation (RAG)** to provide accurate, hallucination-free clinical decision support.

---

## 🚀 Key Features

- **Multimodal Understanding**: Fine-tuned **Qwen2.5-VL** (via `ms-swift`) to extract structured clinical entities (Symptoms, Diagnosis, Medication) from raw medical images with **98% extraction accuracy**.
- **Agentic RAG**: Implements a **Function Calling** mechanism that autonomously queries the **PubMed Knowledge Base** when complex clinical reasoning is required.
- **Efficient Deployment**: Optimized with **QLoRA** and **Int4 Quantization**, enabling the agent to run efficiently on consumer-grade GPUs (e.g., RTX 3090/4090) or single A100.
- **Safety Alignment**: Aligned with medical ethics to reject non-evidence-based queries, ensuring patient safety.

---

## 🏗️ Architecture

The pipeline consists of three stages: **Perception**, **Retrieval**, and **Reasoning**.

1.  **Input Processing**: User uploads an image (e.g., a prescription or lab test).
2.  **Visual Extraction**: The fine-tuned Qwen-VL model acts as an OCR+NER engine, converting visual data into a structured JSON format.
3.  **Knowledge Retrieval**: 
    - The Agent analyzes the JSON data.
    - If specific medical terms are detected, it triggers the `search_pubmed_tool`.
    - Relevant guidelines are retrieved using **BioPython (Entrez API)** or a local Vector Store.
4.  **Response Generation**: The LLM synthesizes the patient data with retrieved guidelines to offer a treatment protocol.

---

## 🛠️ Tech Stack

- **Base Model**: Qwen2.5-VL-7B-Instruct
- **Fine-tuning Framework**: ModelScope SWIFT (QLoRA)
- **RAG & Orchestration**: LangChain / Custom Python Agent
- **Knowledge Source**: PubMed (via Entrez E-utilities)
- **Quantization**: AutoGPTQ (Int4)
